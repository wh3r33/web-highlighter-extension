> Премиальное Chrome-расширение для сохранения важных фрагментов текста прямо с веб-страниц: выделяйте, классифицируйте, добавляйте заметки, ищите и экспортируйте подборку в Markdown.

## Архитектура

Расширение разделено на три независимых контекста Chrome Extension: content script, popup и background service worker.

```text
Веб-страница
   |
   | 1. Пользователь выделяет текст
   v
Content Script
   |
   | chrome.runtime.sendMessage(...)
   v
Background Service Worker
   |
   | chrome.storage.local
   v
Локальное хранилище Chrome
   ^
   | chrome.runtime.sendMessage(...)
   |
Popup
```

| Часть | Файл | Ответственность |
|---|---|---|
| Content Script | `content/content.js` | Отслеживает выделение, показывает панель, создает подсветку, восстанавливает выделения на странице. |
| Popup | `popup/popup.html`, `popup/popup.css`, `popup/popup.js` | Показывает архив, поиск, группировку, заметки, удаление, открытие источника и экспорт. |
| Background Service Worker | `background.js` | Принимает runtime-сообщения и читает/записывает данные в `chrome.storage.local`. |
| Manifest | `manifest.json` | Описывает разрешения, иконки, popup, service worker и content scripts. |

<details>
<summary><strong>Как движутся данные</strong></summary>

1. Content script формирует объект выделения: текст, URL, заголовок страницы, категорию, заметку и timestamp.
2. Content script отправляет `SAVE_HIGHLIGHT` в background service worker.
3. Background service worker сохраняет массив выделений в `chrome.storage.local`.
4. Popup запрашивает `GET_HIGHLIGHTS` и рендерит сохраненный архив.
5. Удаление и обновление заметок проходят через те же runtime-сообщения.

</details>

## Установка

Деплой не требуется. Это локальное Chrome-расширение, которое загружается через режим разработчика.

1. Склонируйте репозиторий:

   ```bash
   git clone <repository-url>
   cd web-highlighter-extension
   ```

2. Откройте Google Chrome.

3. Перейдите на страницу:

   ```text
   chrome://extensions
   ```

4. Включите **Developer mode** в правом верхнем углу.

5. Нажмите **Load unpacked**.

6. Выберите папку проекта `web-highlighter-extension`.

После загрузки иконка расширения появится в панели инструментов Chrome.

> **Важно:** если Chrome показывает ошибку загрузки, проверьте, что выбран именно корень проекта, где находится `manifest.json`.

## Использование

1. Откройте обычный сайт, например статью, документацию или учебный материал.
2. Выделите фрагмент текста мышью.
3. В появившейся панели выберите категорию.
4. Нажмите **Сохранить**.
5. Добавьте заметку или сохраните без нее.
6. Откройте popup расширения через иконку в панели Chrome.
7. Ищите, редактируйте заметки, удаляйте, открывайте источник или экспортируйте выделения в Markdown.

## Privacy & Security

| Принцип | Статус |
|---|---|
| Локальное хранение | Все данные сохраняются в `chrome.storage.local`. |
| Без серверов | Расширение не отправляет данные на внешний backend. |
| Без аналитики | В проекте нет analytics SDK и счетчиков. |
| Без tracking | Расширение не отслеживает поведение пользователя. |
| Без remote API calls | Код не делает сетевых запросов к внешним API. |

Расширение сохраняет только те данные, которые пользователь явно добавляет через выделение: текст, URL страницы, заголовок страницы, timestamp, категорию и заметку.

## Technical Details

| Технология | Использование |
|---|---|
| Manifest V3 | Современный формат Chrome Extension с service worker. |
| Chrome Extension APIs | `chrome.runtime`, `chrome.tabs`, `chrome.storage`. |

## Ограничения

| Ограничение | Причина |
|---|---|
| Не работает на `chrome://` страницах | Chrome запрещает content scripts на внутренних страницах браузера. |
| Не работает на страницах Chrome Web Store | Chrome ограничивает расширения на этих страницах. |
| Восстановление основано на поиске текста | Расширение ищет сохраненный текст в DOM после перезагрузки. |
| Повторяющийся одинаковый текст может восстановиться неоднозначно | Если на странице несколько одинаковых фрагментов, может быть выбран первый подходящий. |
